# Current quality v1

Private operations: `POST /internal/v1/quality/records`, `GET /internal/v1/quality/operations/{operation_id}`, `GET /internal/v1/quality/jobs/{job_id}/current`.

The authenticated adapter supplies current identity, selected business, job assignment, qualification, exact accepted scope, completed work, canonical watch commitment, retained quote/policy, custody, held payment and incidents. Request fields never supply authority. Reads and duplicate lookups require fresh permission and matching job/business scope. Calls have a finite timeout; unavailable authority returns pending/unavailable, never a pass. The authority snapshot is valid on the half-open interval checked_at through valid_until. All instants are authoritative UTC.

The immutable command binds the operation, actor, business, job/watch, scope/work/assignment revision and retained quote/policy. A retry uses the identical command and operation. Conflicting reuse returns conflict. A stale quality revision or source revision requires reload. Missing required completed lines blocks readiness. Each required accepted line records actual applicable tests, final condition, fit and returned links/parts, including a reason when a check is inapplicable. Any unsatisfactory check records rework. A later successful check requires a new operation and current work revision. Assessment, approval and quality require three distinct qualified people; quality also excludes all performers. Platform coverage obeys the same independence rules. Only brand/dealer jobs are supported; no private-sale inspection is synthesized.

A satisfactory record is only a quality result. Current handover permission additionally rechecks all source bindings, accepted work, custody, payment, exclusive commitment and loss/damage holds. It cannot release funds, create receipt or publish service history.

Records and actual readings are private. No public previews, logs, events or evidence bytes contain them. No file-upload operation is exposed. The receipt and minimal invalidation event commit atomically. Operation lookup recovers a lost response without another result. Unknown operations are unavailable, never successful. The local persistence adapter exercises these semantics; production database registration and the S10 provider remain connected prerequisites.

Accepted-line reads use `GET /internal/v1/quality/jobs/{job_id}/lines?offset=…&limit=5` with a server-authoritative total, revision-bound line identifiers and required test keys. Every page rechecks current permission and the same source bindings; mismatches require reload. Pages contain at most five lines and the bounded record contains at most 1,000 lines. The private view retains visited findings in memory and submits only after every required line is present and complete. Page failures retain findings and offer the same page read again. Production page composition remains deferred.
