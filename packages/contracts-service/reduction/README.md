# Reduction v1

`POST /v1/reduction/records/{record_id}/commands` accepts `Command` with a stable operation reference. `GET /v1/reduction/operations/{operation_id}?record_id=…&organization_id=…` resolves a lost response after current authorization. `GET /v1/reduction/records/{record_id}?organization_id=…` returns the current private record. No collection endpoint or private file upload is provided.

Errors are stable codes: `denied` (403), `stale` and `operation_conflict` (409), `unavailable` (503), validation (422). An uncertain response remains pending; retry the identical command or look up that operation. Lookup never executes work. Receipts retain actor, business, subject, watch, source, assignment, quote, policy and resulting revisions. The source revision must change whenever compatibility, commitment, accepted scope, custody, money, assignment, incident or return-exception facts change.

The host supplies `reduction_authority.guard(request, record_id, organization_id, kind)` as an asynchronous context manager yielding `Authority`. It must authenticate afresh, enforce record scope, bound dependency calls, and hold the canonical source revision fence until the protected transaction commits. `kind` is request, record or read. The host must not provide this guard from a projection. Missing guard is unavailable. This additive module does not register itself or invent provider endpoints.

A request preserves a target and supported choice; it is neither permission to execute nor final fit. The guard enforces current identity, business membership, assignment and record permission, the canonical exclusive watch commitment, retained exact quote economics, accepted scope and independent role boundaries. It binds actual fit approval and a responsible person with a next review within 24 hours for unresolved work. Recording requires accepted scope, held payment and current custody with no incident. All removed parts are actual compatible identifiers. Replacement straps must match exactly one compatible accepted_straps entry for the selected choice and current source, quote and policy revisions. An absent list denies replacement work; a new part requires renewed scope acceptance from the source owner. Required buyer-owned parts must be returned to the agreed authorized recipient. A supplier-exchange exception must be actually accepted by this buyer for these exact parts and current source/quote revisions. It cannot excuse missing buyer-owned parts. Unconfirmed fit or incomplete returns remain unresolved. Resolution here records reduction facts only; it never authorizes handover, payment release, quality approval or service history.

UTC source validity is checked strictly before expiry; equality is expired. This module schedules no appointments. Measurements preserve entered unit, source and method; 17.5 cm equals 175 mm. No universal links-per-length conversion is used. Development fixtures are synthetic and confer no execution permission.
