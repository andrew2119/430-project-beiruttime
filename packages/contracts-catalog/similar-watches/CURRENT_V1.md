# Similar watches v1

Public, nonmutating operation: `GET /v1/similar-watches/{subject_id}` with UUID `operation_id`, positive `expected_revision` and an offset divisible by 20. Operation lookup repeats this exact address and parameters. Retry the same reference after a lost response or restart; every lookup rechecks current public scope. No stored answer grants access or reserves stock. No private read or write is exposed. Identity and selected-business parameters are rejected rather than used to widen public scope.

`current.py` is the closed wire schema. The eligible public source remains a matching anchor when its stock is unavailable. Only available published stock from that same public query can enter the alternatives. Withdrawn, hidden, restricted, unavailable and duplicate physical watches are excluded. An unavailable current authority makes the entire answer unavailable. Provider calls have one overall one-second deadline, no internal retries and a 1,001-record source ceiling (source plus up to 1,000 alternatives); excess requires unavailable, never an incomplete total.

Matching uses normalized Unicode text (compatibility normalization, case folding, trimmed/collapsed whitespace). A reference match requires the same nonempty reference AND brand. Next comes same brand. Otherwise price-band means an inclusive 80%–120% of the source's stated USD listing price, using integer cross multiplication. Missing price cannot match a price band. Order is rule priority, absolute price difference (missing price last), then listing UUID. Never include the source physical watch. These rules are descriptive, with no personal history or inferred preferences. Listing prices are not quotes or purchase permission.

`stale` requires reviewing the current source revision. `denied` reveals no private source facts. Timeout, malformed responses, unknown authority or a truncated provider set produce `unavailable`, with the same operation reference available for retry. Empty means a complete current query found no alternatives. There are no acknowledged mutations to persist.

Runtime registration belongs to the catalog composition owner. Connected publication, commitment, restriction and permission proofs remain owed until that owner mounts the operation with the actual producers.

Private seller scope dependency: the composition supplies an async `seller_scope(public_listing)` read returning exactly `{listing_id, seller_id, listing_revision, eligible}` with a current boolean eligibility decision. Listing, seller and revision must match. A false decision excludes the record; absent, malformed, stale or timed-out decisions make the operation unavailable. This dependency is a proposed contract with local fixtures until its producer is connected. Business scope uses the current public business read already used by discovery.
