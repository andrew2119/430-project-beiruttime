# Server-interpreted Beirut scheduling

Additive web adapter v2, L12-owned; the canonical Auction API remains the permission/admission authority. All money is USD integer cents on the wire and exact dollars in the existing form. Historical non-USD records and old UTC draft timestamps are never reinterpreted.

`POST /api/web/v2/auction-schedules` with `starts_local`, `ends_local` in minute-precision `YYYY-MM-DDTHH:mm` and `review_only: true` returns `{starts,ends}`. Each interpretation contains `local`, `utc`, `offset` and `time_zone: Asia/Beirut`. This calculation creates no auction, reservation or payment. Origin and a sign-in header are required; no private information is returned. The timezone database supplies the applicable offset, not the browser's timezone. Missing/repeated local times require correction (`invalid_beirut_time` / `ambiguous_beirut_time`). Positive duration is at most 90 days.

The current seller reviews the dates and offsets. Confirmation sends the same local fields plus exact `confirmed_starts_at`, `confirmed_ends_at`, listing reference, `currency: USD`, opening/reserve cents and increment bands, under the retained Idempotency-Key and optional current organization query. The server independently reinterprets and compares the reviewed instants, then reuses the existing authenticated gateway and bounded Auction dependency. Its current principal, publication grant, physical fence, server clock and canonical transaction still decide admission. Removed extension or auction-purchase configuration refuses.

There is no separate engine and no browser UTC conversion. If the reply is unknown, the existing actor-owned Auction operation lookup reconciles the same key. Locale changes do not alter component identity, typed values, private in-memory reserve, reviewed offset or operation key. Passwords/private files are not part of this form and never enter draft persistence. New public draft storage records the explicit timezone; old UTC drafts require new local timestamps. No browser/heavy acceptance is claimed by these focused adapter checks.
