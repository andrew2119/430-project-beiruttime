# Own auction results v2

GET /v2/my-results accepts view (won, lost, no_sale, unpaid or released),
limit (1 through 100) and an optional opaque cursor. It consumes the current
Auction result and Orders financial facts. No endpoint availability is implied
by this contract. A missing provider returns unavailable with no rows or total.
Cursor binds current actor, organization, filters and source revision. A changed
revision restarts paging explicitly; no mixed snapshot or client-side totals.

Each source row includes the required is_demo fact and binds buyer_id, auction_id, watch_id, revision, ended_at,
result_recorded, participated, winner_id, sale_qualified, final_minor, order_id,
financial_state and source_revision. Currency is USD. Money is finite integer
cents. ended_at is an authoritative UTC instant. Authorization supplies current
actor_id, organization_id, allowed and expected_source_revision for each read.
These are provider facts, never caller-supplied permission claims.

No bids or below-reserve means no_sale, no winner, no order and no completed
sale. A no-sale source may supply null financial_state. Earlier sources may
supply pending for this outcome. The projection returns null in either case.
A qualifying other winner means lost. Auction standing and the winner's own
financial_state are separate. Every qualifying winner remains in the won view.
The unpaid view includes unpaid and unpaid_released financial states. The
released view requires actual released completion. The financial_state is null on
lost and no_sale rows. Unknown payment and pending allocation without an
order direct the buyer to support. Other own rows with an order direct the
buyer to that order. No receipt creates authority to charge or release funds.
The released view includes any qualifying released result in the buyer's
participation scope. A losing buyer keeps the lost standing and sees
completed_sale=true, without the winner's order reference. Only actual
released completion is counted in the sold archive. No market valuation
is calculated. Private ceilings and evidence are excluded by construction.
Operation lookup for reads is not a write receipt; canonical result revision
and original winner cannot be rewritten by this projection. Missing, denied,
stale and timeout cases fail closed. Repeated source delivery yields the same
projection and never creates a second order, notice or financial operation.

Result rows carry listing_id separately from the physical watch_id. Buyer activity links bind listing_id and auction_id so relisting preserves
access to the selected auction history.
