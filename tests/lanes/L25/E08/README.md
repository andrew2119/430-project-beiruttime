# Phone journey contract checks

Run `node --test tests/lanes/L25/E08/contract.test.mjs` from the repository root. This directory contains development contracts, synthetic responses and an executable acceptance matrix. It does not register routes or provide transaction authority. The success response is a synthetic contract example, never a seeded payment, bid or inspection.

`contract.mjs` publishes the versioned envelope, operation lookup, retry bounds and bilingual recovery vocabulary. `fixtures.mjs` supplies deterministic success, denied, stale, timeout, duplicate and lost-response examples. Reconciliation compares current identity, business, access, assignment, retained quote, policy and source revision before displaying a response, including when confirmation is missing. Assignment changes purge private state. Quote and policy changes deny reconciliation. Assignment and quote identifier/revision pairs are required; explicit null pairs mean inapplicable scope, never omitted authority. Policy revision is always required. Receipts echo these bindings and carry the current result revision, which cannot precede the source revision. These pure checks exercise the consumer model only; real authorization stays with each producer. No offline bid or payment queue is provided.

`manifest.mjs` exports every required journey, language, theme, device and recovery combination. Call `summarize(records)` with external observations to obtain exact pass, fail, skip and remaining identifiers. Missing observations remain owed; skips require a reason. Fixture results cannot count as connected passes. Keep observations, screenshots and execution records outside the repository. References must be opaque private record identifiers, never private evidence or credentials.

After separate release clearance, the connected run must replace examples with authoritative operations from O07, O08, T02, S11, A07 and BASE-ADOPT. Verify serialized auction admission, Pricing v3 validation/retention/commit and Orders v3 durable payment notices against the published freezes. Missing interfaces remain a connected prerequisite; these local operation names are development lookup keys, not invented endpoint claims. Repeat stale, denied, timeout and duplicate cases after each replacement.

For every matrix row, verify the actual page and current actor/business/assignment bindings. Positive journeys must reach their real persisted outcomes. Negative journeys must prove no unauthorized write, charge, release or private read. Lost-response and restart checks reconcile the same operation against durable receipts; offline attempts never queue a financial command. Fail one upstream and keep unrelated slots usable. Change identity/access and confirm private views and retained answers are purged, including late responses.

The separate browser run must measure `window.innerWidth === 390` and `window.innerHeight === 844`, screenshot both languages/themes and desktop, and inspect overflow, safe areas, 44px targets, 16px coarse inputs, keyboard focus/restoration, 200% zoom and reduced motion. Test the same mounted form across language changes with password, private file, options, query, filters, step and operation reference retained only in memory. Inspect cookies, storage and offline caches for private bytes; logout must clear private state. Physical-device observations require an actual phone before any complete-phone claim.

Use missing values, mixed Arabic/Latin text, emoji and 0/1/large totals; traverse all 1,000 records through real pagination against server totals. Verify dollar input/display preserves exact integer cents. Exercise authoritative UTC boundaries just before, equal and after, retained economics separately from execution permission, and Beirut civil appointments including missing/repeated civil times.

For each actual route record its data/read key, readiness before press, intent warming, retained answers, content during refresh, first-load placeholders and single arrival behavior. Measure the first frame and page size rather than infer a pass from source. Canonical shell, fields, surfaces and motion remain owned by their existing modules. This directory creates no alternative runtime composition.

Connected positive/negative/recovery runs, database durability, real browser geometry, screenshots, keyboard behavior, storage inspection, page-size/first-frame measurements and physical-phone feel remain separate required proofs. No production build, full suite, connected stack or browser run is part of this module command.
