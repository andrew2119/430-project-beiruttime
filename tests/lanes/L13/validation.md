## Reproduce

Use the pinned pnpm shim and run heavy work only through `bt-heavy.sh`; builds require `bt-heavy.sh --build` and its current disk floor. Scripts stop only their own native processes, browser session and Compose services in `finally` blocks.

1. `python3 infra/foundation/package-contracts.py .venv/l13-contracts`
2. `.venv/bin/python tests/lanes/L13/run-local.py orders` (or `catalog` / `auction`).
3. `.venv/bin/python tests/lanes/L13/check-docker.py` through the build wrapper; reuses this checkout's pinned dependency images.
4. `.venv/bin/python tests/lanes/L13/check-browser.py` through the heavy wrapper. Native ports 58130–58135, browser 58139; all explicitly bound to 127.0.0.1 after free-port checks. The existing PostgreSQL/demo stacks are never stopped.
5. Add `L13_PROOF_AUCTION=1` for the connected winner journey. `L13_ONLY_AUCTION_BACKEND=1` is a diagnostic backend-only run, not full browser acceptance. `L13_EXPECT_CLOSE_PENDING=1` is only for the unavailable-provider negative case, never a replacement for successful final allocation.
6. `web/node_modules/.bin/vitest run --config tests/lanes/L13/web/vitest.config.ts`; `cd web && pnpm run typecheck && pnpm run lint`.
