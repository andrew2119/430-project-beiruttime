## Reproduction helpers

- `provision_connected.py`: creates only generated local restricted database namespaces, no domain facts. Credentials stay in ignored `artifacts/` files.
- `compose.isolated.yaml`: the five isolated domain runtimes, bounded resources and read-only source inputs.
- `bootstrap_identity.py`: explicit isolated Identity-only initial principals, requiring `BT_L03_ISOLATED_BOOTSTRAP=isolated-principals-only`; invoke inside Identity with `PYTHONPATH=/app:/opt/domain-contracts`. Never a product route/startup seed.
- `connected_demo.py`: real assignment, scoped evidence reads, verdict, sample onboarding/membership, twice-run import and public attribution checks. Credentials/private proof never enter its output.
- `browser-smoke.sh`: set `BASE_URL`, the actual `LISTING_ID` and `ALL_EDITOR_STEPS=1` for the 56-case matrix. Use an actual Identity browser session, not a synthetic token adapter.
