## Post-proof hardening

Command lifetimes now abort on keyed account/business view unmount, including file reads that resolve after a scope change. Requests refuse an already retired signal before calling the shared credential coordinator, and download callbacks cannot create a late private Blob. Unit tests cover this late-continuation admission fence and live signal/revision/idempotency forwarding. The latest published Identity coordinator is applied locally and every L09 request passes its view-owner `accessFingerprint`, so a stale callback cannot acquire new-account credentials even before React unmount cleanup. Reclaiming an appealed case now returns its actual appealed state rather than a misleading assigned result. The current Directory V1 unsupported-service 409 is treated as eligibility denied, not an outage; selected-organization Identity 401 stays 401 so the shared browser coordinator can refresh. Downstream subject/queue/receipt 401 outcomes also stay distinct from permission denial, including private detail revalidation. Receipt validity must be the boolean true and revision an actual positive integer; coercible strings, floats and booleans are rejected. A final browser smoke exposed same-selected-case claim recovery retaining a prior denial; choosing/claiming a case now remounts its detail, and the real release/reclaim flow confirmed fresh evidence opens automatically without a manual retry.
