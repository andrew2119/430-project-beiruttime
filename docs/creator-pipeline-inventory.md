## Intentional product-boundary differences

- Light and Dark only; source Classic tokens remain for provenance, but are not a third theme option.

- Existing account APIs have no generic profile-photo/name-edit endpoint. Settings shows the real session profile and links to existing Account security controls; no fake save/upload action is introduced.
- Counts are rendered only when backed by real service state. No fabricated badge, notification, chat or companion integration.
- Creator image provider resolution/telemetry is not copied; ImageFrame ports reserved geometry/decode reveal over the marketplace caller-owned source policy.
- Desktop rail stays on CP’s left side, including Arabic; content reads RTL. Phone drawer motion is mirrored for Arabic.
- Dashboard replaces the old marketing-style home; every door opens an existing registered route.
