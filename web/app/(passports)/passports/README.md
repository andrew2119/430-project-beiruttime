# Public passport route

`/passports/{passport_id}` requires the existing canonical shell and its shared
read provider. The current route selection does not supply that scope, so the
public destination cannot render yet. Its owned read route accepts no expansion query and uses the bounded
Trust dependency to read and verify the closed public summary. Only a successful
signature check with an identical document becomes verified. No private identity,
serial, evidence or source bindings are forwarded.

Read key: `passports.public.v1`, passport ID, `verification.v1`. Locale is absent
from that key; language changes preserve the mounted page and recovery reference.
Retries repeat the same public read, never create an issuance operation. The mounted reader uses the shared access-scoped memory cache, retaining answers
between visits and during refresh. Failed refreshes retain the previous answer.
Only a read without an answer draws shared skeletons. The shared arrival boundary
claims one arrival per reference and access scope.
No command or private evidence is warmed or cached.

Shared page-table registration, route-intent warming, arrival motion, page-size measurement and canonical
shell adoption remain with shared composition. The public destination requires
that composition to supply the existing shared page scope; it does not create a
second provider. The current shared registry and validator accept only internal
example destinations, so the public delivery row and intent dispatch remain
blocked on their owner. The page-contract check remains failing until that change. First-frame/theme, connected
provider, browser geometry, keyboard and physical-phone proofs remain deferred.
No speed or phone measurement is claimed by these module checks.

Required shared composition changes are outside this module:

- `web/shell/foundation/path.ts`: select the canonical shell for the exact public
  passport destination on direct load and navigation, including localized paths.
- `web/lib/page-speed/pages.json` and `web/scripts/check-page-contract.mjs`:
  register and validate the public dynamic destination and its owned view/read
  definition, without a frozen-debt entry or a synthetic read policy.
- `web/lib/page-speed/pages.ts`: match the bounded passport identifier and dispatch
  the same `passportRead` definition from `web/features/passports/reads.ts` on intent. Preserve its locale-independent
  key, current access scope and public-only warming policy.

The destination regression checks the root shell selector before supplying its
shared read scope. It currently fails because that selector chooses the older
shell; root composition must select the canonical shell before this destination
is accepted. No fallback shell, private
cache or feature-local provider is supplied to conceal that missing composition.

The read definition is separate from the mounted page so shared intent dispatch
can load the public read without importing the page, its view or locale dictionaries.
This separation supplies no shell selection or delivery registration by itself.
