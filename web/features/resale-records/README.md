# Resale history composition

The seller records composition is additive and awaits the shared runtime's authenticated route registration. It mounts only inside the existing canonical shell; it does not supply a shell, provider or navigation outlet. The workspace uses the canonical page frame and header.

The current default has no provider and displays unavailable in either language. An authenticated adapter supplies the current access key, immutable released-sale candidate and bounded transfer boundary. A changed identity or access key remounts the private workspace. Access-change notification clears its reference and aborts pending work. Language changes retain the mounted workspace and exact pending command in memory.

No private file or password input is used. No browser persistence is used. There is no history collection or partial list to mislabel as a server total.

## Delivery contract

Data/read key: no current read is mounted. The eventual scoped operation lookup must use the shared read definition keyed by current access scope and exact operation reference. Current authority is checked again by the server before returning a receipt.

Ready before press: route registration and full destination payload proof are owed. Data on intent: no command is warmed; eventual non-audited scoped reads require the shared intent boundary. Retained answers: none are cached by this module; eventual answers must use shared access-partitioned retention. Refresh content: pending operation references stay visible during same-command retries. First-load placeholders: the canonical state supplies the loading announcement only while the first response is pending. Arrival motion: inherited from the eventual canonical shell; no local animation is added. First frame currently displays unavailable without a speculative successful transfer.

Shared route delivery registration, provider integration, authenticated transport, durable deployment database, outbox dispatch, browser restart recovery, page-size measurement, EN/AR light/dark desktop and actual 390×844 geometry, screenshots, keyboard, reduced motion, contrast and physical-phone checks remain owed. No connected or visual completion is claimed. The current shared page registry supports internal routes only; extending it belongs to its steward. The additive composition is intentionally not a mounted route until that registration exists.
