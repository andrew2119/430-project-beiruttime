# Repair quote review

The repair route uses the canonical page layout, header, fields, controls and state components through the shared Pricing composition. It keeps form identity, optional selections, fee acknowledgements and operation keys in memory across an in-place language change. Current identity/access changes remount private forms. No private files or passwords are requested or stored.

The page read key is `['l14', scope, 'repair', page]`; issue context uses `['l14', 'repair', 'context', contextQuery, suffix]`. Pages contain at most twenty records with server totals. Mutations invalidate the scoped list. Retained query answers remain visible during refresh; skeletons appear only without an answer. Receipt recovery repeats the exact operation key. Decline remains available after the preview deadline without authorizing work or custody release.

The root owns providers, shell, first-frame theme and fonts. This feature adds none. Shared navigation owns route warming; this feature currently has no shared data-on-intent registration. Ready-before-press data, warmed read equivalence, retained-answer timing, one-arrival motion and per-page bundle measurements require the separate frontend verification. They are not certified by this module.

Unresolved decision payloads, keys and errors remain in the identity-scoped workspace above pagination. Returning to a card retries its original command, including after an expiry refresh. Conclusive results clear that command; identity changes clear the workspace.

Unsent card drafts also remain in that workspace, keyed by current scope, quote identifier and quote revision. Pagination preserves selected lines, fee acknowledgements and the terms checkbox; a new revision starts a fresh draft. The localized support link opens the inbox before the acceptance controls.

Unresolved creation commands stay in the identity-scoped workspace, partitioned by business scope and assessment context. Returning to that scope offers recovery with the retained payload and operation key before another creation. Decided checkboxes use the retained decision line identifiers rather than unsent draft choices.

An unresolved decision offers recovery even before an error arrives. Expiry displays unavailable return coordination until responsibility is durable. Declined views separate disclosed fees from acknowledged fee lines and show no payable job total or confirmed collection.
