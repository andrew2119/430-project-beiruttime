# Reduction page contract

The route composes the canonical page frame, header, fields, choices and states inside the root shell. Its one current-record read is `reduction.v1 / access fingerprint / organization / record`, defined once through the shared read boundary. Private answers are open-only, immediately stale and retained only within the shared access partition. They never authorize a command. Intent data warming is withheld for private records; module warming and route readiness belong to the shared route steward. No second cache, provider, shell, arrival animation or theme is introduced.

The initial frame shows a current-record placeholder only while there is no answer. Refresh keeps existing content; command permission is always rechecked. The same mounted form owns language-independent values and the exact pending command. Changing language changes labels only. Changing identity removes the private subtree. Unknown command results lock record switching and keep the same operation reference for retry. Inputs and commands remain in memory; no files are collected here. The page contains one bounded record with at most 100 actual parts, not a sliced collection or guessed total.

`delivery-contract.json` is the feature-owned declaration of the route, page, shared view, content boundary and private read. The separate foundation change consumes these declarations and supplies the existing root read scope. No shared page-table, validator or shell edit belongs to this feature. Root route adoption and measured page-size proof remain deferred until that change is present.

The route error boundary presents bilingual unavailable recovery if shared composition fails. The composition tests use the real read hook, verify the declaration and confirm that the form renders its initial loading state under the canonical provider in both languages. Connected direct-entry/navigation and consumed-table assertions remain explicitly skipped while their shared prerequisites are absent; they run when those prerequisites are present. These isolated checks do not certify a connected request journey.

Ready-before-press, module warming, first-frame theme/font order, the single arrival recipe and measured per-page budgets belong to the shared composition. Their connected measurement remains owed, together with current provider integration, database durability and the separate desktop/phone visual and keyboard matrix.
