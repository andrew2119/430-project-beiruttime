# Counteroffer view boundary

The exported view consumes a current private PageRead and scoped command, operation
lookup and exact-quote callbacks. Runtime route registration belongs to the composition
owner. No route is registered by this additive module. Mount with scope equal to the
current access fingerprint and permission revision; locale must never form its key.
Pass stable PageRead identity until the selected subject or access scope changes.
Private state is held in memory, and access changes remount and clear that state.

The read key must bind counteroffers.v1, subject, watch, actor, selected organization,
source revision and authority revision within the shared access-scoped cache.
Use definePageRead with open-only warming: private negotiations are not public prefetch.
Shared usePageRead retains the current answer during refresh, uses first-load-only
loading states and clears access-scoped answers. An uncertain write retains its exact
command reference and exposes operation lookup; it never sends a new command implicitly.
The shell owns arrival motion, route readiness and first-frame theme/font order.
Ready-before-press route warming, intent registration and per-page size measurement
remain owed at route composition; no speed measurement or transferred improvement is
claimed. There is no local palette, motion table, shell or cache.

Connected route, denied-read classification, focus review, long mixed-script content,
actual 390 by 844 geometry in both languages/themes, physical phone behavior and
same-mounted language retention remain owed. The view displays one current negotiation,
not a list; list pagination and server totals belong to the future history read.

The terms input supplies complete English and Arabic accepted terms, return conditions,
assurance conditions and a local support link, bound to quote identifier, quote revision
and terms revision. Missing or mismatched terms disable commercial review and acceptance.
Permission errors use status 401/403 or code denied/forbidden; they clear local private
state and hide retained read data until a fresh access scope mounts. Command results
replace older read revisions; closed results explicitly report closure.

The required subjectId and watchId identify the selected negotiation independently of
its read result. Together with scope and actor they key the form lifetime; switching
subjects clears returned counters, drafts, reviews and pending commands immediately.
Read and command responses must match that identity before display or retention.
