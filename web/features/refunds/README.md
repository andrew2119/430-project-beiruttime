# Refund view boundary

`RefundView` is a private additive view for the shared shell. Runtime composition supplies a stable, scope-bound `RefundPort` and mounts the view without a locale key. The default port is unavailable and never fabricates a current balance or successful operation. Route, gateway, page-read registry and shell composition belong to their existing owners.

The mounted read uses the shared definition and provider with key `['refunds.v1', 'current', access_fingerprint]` inside the provider's current access partition. A composed port must bind one selected organization, subject and watch to that access fingerprint. A scope or port change requires a new form identity; a language change uses the same form. The current-read payload contains only the immutable decision binding and server remaining principal, never private evidence. A read must recheck current authority. It never authorizes a write.

Read warming is `open-only`: no private data is fetched speculatively. Ready-before-press and destination data-on-intent require the shared route owner to connect this same definition; this leaf does not create a warming engine. The shared provider keeps authorized answers between visits, shows existing content during refresh and uses loading state only before the first answer. Authoritative denial hides all retained private content and actions, including the amount and operation details. The exact unresolved command remains only in mounted memory for reconciliation and is never displayed while access is denied. Denial remains closed through retries and temporary failures until an explicit reload successfully rechecks current scoped access. A retained amount is explicitly marked last recorded during refresh or a temporary failed read. A returned operation triggers a current-basis refresh and keeps its exact reference visible.

The root owns theme, fonts, session restoration and the first-frame shell. The view adds only the shared page frame, header, body and canonical controls. It adds no navigation, main landmark, notification outlet, provider, palette or motion recipe. No independent arrival effect is introduced. Page size and first-frame behavior have no measurement asserted here.

Dollar text, command and pending reference live only in the mounted memory store. Language changes are presentation-only. Identity/access changes remove that form. This page has no files or passwords and writes no browser storage. The port must bind the authenticated identity independently of command actor fields, honor its abort signal and translate only bounded error codes. `RefundFailure.noEffect` is allowed only for an authoritative, definitive refusal that guarantees no reservation or payment effect. Generic failures and absent lookups retain the command; a later denial cannot discard earlier uncertainty. An explicitly reviewed new command is allowed only after that guarantee and a successful fresh scoped read.

The page displays one current decision and operation, not an activity collection or client-computed total. Lists, pagination and counts belong to a separately composed history read. No synthetic history is presented as financial proof.
