# Public discovery composition

Browse and search use the shared PageLayout, PageHeader, fields, Select, State, skeletons and animated cards. Watch detail uses the same header, cards and Dialog gallery. Direction, theme, navigation and query ownership remain in the root shell.

Typed price filters are dollars. Applied links retain exact text, and the request adapter converts to integer USD cents. A legacy cents link is converted exactly to dollars. Applying criteria resets the cursor; the controlled draft retains unsent values independently of applied criteria. Locale is excluded from draft and comparison identity; neither translation submits criteria. The form stays mounted when applied criteria change, and only an explicit criteria change resets its draft. Cursor-only navigation preserves unsent filters. Full-document language navigation in the shared shell still destroys that identity and requires a shared correction before language-retention acceptance. Comparison keeps at most three identifiers in memory and rechecks each public detail. Similar results disclose same-brand matching within the current bounded result page.

Documents, modifications and component wear come from listing declarations. An unmodified declaration does not certify originality. Seller counts, ratings, dated history and inspection results require a current bound public response. Missing facts stay unavailable. Public photos and credits remain separate from private evidence.

## Read and arrival contracts

| Method | Current behavior |
| --- | --- |
| Ready before press | Route links use the shared navigation boundary; no private shell or route loader is installed. |
| Data on intent | Public watch links warm the exact detail read on pointer intent and keyboard focus. |
| Retained answers | Root query cache retains `['discovery','public',criteria]` and `['discovery','public','watch',id]`; locale is excluded because underlying facts are identical. |
| Content during refresh | Cached content remains mounted during a successful background refresh; failed detail refresh removes sale controls. |
| First-load placeholders | A pending read without cached data uses shared skeletons; no second provider or speculative success frame exists. |
| One arrival | Shared list and dialog primitives own entry/exit motion and reduced-motion behavior. |

Search totals use the optional current Orders public count response, not page length or a local stock estimate. Missing count support is explicitly unavailable. Public reads never reserve or authorize a charge. All private commands and permission checks stay with their slot owners.

Seller facts and paginated available listings are composed as a section inside watch detail. A standalone seller route remains deferred until the shared PageFrame and usePageRead interfaces are published. No delivery declaration substitutes for those interfaces. Connected read and first-frame verification remain owed.

The source checkout has newer speed and first-frame recipes than the current shared exports. Discovery consumes the existing boundary; global cascade, shell, size gates and foundation exports remain their steward's responsibility.
