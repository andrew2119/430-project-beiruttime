# Public seller page

The feature-local `delivery-contract.json` declares the public route. The view
uses shared PageFrame and PageHeader composition and its read uses usePageRead.
The shared scope owns cancellation, access-bound answers and retry behavior.
The read key contains subject, page and stable operation reference. Locale changes
and retries retain that reference; changed access or page replaces it. The public
profile_read query criterion preserves it on document reload and grants no access.
Pagination preserves other query criteria and the fragment.

Current permission is checked on every request. Identity is hidden during refresh
and failures. Private evidence and contacts never enter the public projection.
Missing history stays unavailable rather than becoming zero.

The shared shell does not yet supply this declared public route's read scope.
That foundation connection and discovery support remain owed. No local provider
or registry bypass is introduced. Connected identity, business, released sales,
reviews and listing reads remain owed; fixtures do not prove those connections.

Ready-before-press and data-on-intent remain deferred. Answers are retained only
within the shared access scope; refresh hides identity pending current permission.
Initial placeholders use the shared PageLoading composition. Arrival, first-frame
theme and direction belong to the root shell. Page-size measurement remains owed.

The shared language control still requires its owner's in-place update and query
retention. The local mounted check covers locale changes, stable operation retries,
and access changes, but does not establish behavior through that shared control.
Browser keyboard flow, both themes and languages at a measured 390-pixel viewport,
physical-phone feel and connected recovery/restart proof remain owed.
