# Private offer rule screen

The route-ready screen accepts an authoritative current binding and a private
command gateway. No synthetic success is mounted. Runtime registration and the
page delivery registry belong to their shared owner; `screen.tsx` deliberately
is not a route entry until that composition supplies current access.

The caller clears current data immediately on identity/access change and changes
scopeKey for actor, business, record grant and listing. Language is excluded:
the mounted form, dollar input and exact pending command survive locale changes.
No private values enter browser storage, URLs, events or previews.
A denied command hides the form immediately. Explicit reload first removes the
old current data, then supplies authorized current data to the same scopeKey.
A read generation must never be part of scopeKey. Reload clears resolved form
state, but keeps any pending command and typed amount. Only a change of actor,
business, record grant or listing replaces scopeKey and clears private state.
When access is unavailable during a pending change, Reload remains available;
after access recovers, Retry sends the exact retained command and reference.

Delivery contract for composition: read key is
`minimum-offers/v1/{actor}/{organization}/{subject}/{watch}/{access-revision}`.
Use the shared private read definition, open-only warming, retain answers only
within its current access partition, show retained content during refresh and
first-load-only placeholders. The root owns theme/font/provider ordering, shell,
arrival motion and navigation feedback. There is no local cache or provider.
Page registration, six shared speed-method measurements and first-frame size
proof remain owed with composition. No animation is needed for this form.

The screen has no collection: pagination, row counts and thousand-row checks
are inapplicable. Keyboard, mixed-script shaping, both themes and languages,
390×844 geometry with innerWidth=390, physical-phone feel and actual same-document
locale integration remain owed on the separate verification machine.
