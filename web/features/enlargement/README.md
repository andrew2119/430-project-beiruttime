# Enlargement page

The page uses the existing root shell, locale provider, canonical page frame and foundation controls. Locale changes retain the form and action component identities. Inputs and uncertain operation references stay in memory. Unresolved action payloads belong to the identity-scoped page rather than the action form. Refresh, changed revisions and denied reads cannot discard them. The exact reference remains visible with a retry; opening another record and starting another action are blocked until a retained retry resolves or receives a definitive rejection. Action details, completed-line selections and confirmations belong to the identity-scoped page, keyed by request and action type, so pending removal, definitive rejection and newer reads preserve them for correction. Identity/access fingerprint changes replace the private form and its drafts.

The current-record read is `enlargementRead(request_id)` with key `['enlargement.v1', request_id]`, partitioned by the shared access scope. It is private and open-only, with immediate freshness expiry. The shared read retains scoped answers during refresh; command results yield to equal or newer current reads. A denied refresh hides the record.

The six shared delivery methods apply as follows: route readiness belongs to the existing shell; private record data starts on explicit open; retained answers belong to the shared read scope; refresh keeps content; first-load waiting uses the canonical State; navigation arrival belongs to the shell. No additional provider, shell, cache or motion recipe is mounted. Intent warming of private records is disabled. The route's shared delivery-table registration remains with the runtime composition owner, alongside gateway and provider registration. This module does not register itself outside its boundary.

Assessments record actual compatible part quantities and supply state, exact current quote, limitations and target. Acceptance displays retained lines and bilingual terms. Staff explicitly confirm each accepted line of actual work. Independent quality failure requires rework and a new current check. A recorded fit does not mean receipt, financial release or published history.
