# Private job authorization

`service.py` coordinates bounded current reads and durable retry receipts. `providers.py` defines the required production boundary. No runtime route is registered by this module: the composition owner must provide authenticated producers and the canonical atomic Orders operation. The receipt database stores references and outcomes only. It contains no private files or evidence. Close the coordinator at shutdown.

`service_adapter.py` selects ordinary repair without customization approval. The current-scope provider must use actual S02 acceptance and O03 held money. No local fixture is production authority.

An authorized receipt records a past outcome; it never replaces current start permission. Scheduling, start, quality, custody, dispute and release remain separate canonical operations. Release must check actual tests, fit and returned parts, independent current quality pass, actual authorized receipt, the full 168-hour dispute window and no current hold. This module does not release funds.

The status component is an additive canonical-control view for the composition owner. It takes current access-scoped state and preserves its action reference on retry.
