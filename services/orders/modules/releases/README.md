# Release module

Compose router_for with the current identity dependency and Releases with the sole Orders journal implementation. No module-local balance, transfer sender, refund path or second allocation exists. There is deliberately no successful runtime fallback when a provider is absent.

The journal reserve method invokes conditions inside its existing order/hold transaction. Current source bindings and current authority must be resolved there, including assigned independent private inspection, platform business assurance or actual job quality completion. Snapshot booleans describe current authoritative source assertions, never cached screen values. Sources must bind the current watch, work/scope, assignment and policy revisions. Inability to establish any assertion means sources_current is false or the call is unavailable.

Private reads require current record permission, identity, selected business and assignment. The original actor/organization owns operation lookup and recovery. The operation key is immutable across all retries; a conflicting payload denies. Pending recipient and retained fee versions remain frozen even after later source changes. Journal reservation, outbox dispatch and callback inbox behavior are the atomic contract in CURRENT_V1.md. Runtime composition must satisfy that contract before exposing release execution.
