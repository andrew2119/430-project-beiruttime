# Private review integration

Entry point: `routes.py:router`. Apply only `migrations/L20_0001_private_review.sql` through the service migration owner. The current shared discovery ceiling admits L01 through L11; adding an L20 registration would break startup. Registration and runtime composition are deferred to that owner. Contract packaging also needs the shared discovery owner to publish `bt_contracts.eligibility.private_review`; focused tests load the exact owned source directly.

The router requires `app.state.private_review_authority.fence(token, case_id)`. Missing integration returns 503. This bounded asynchronous context manager yields the current Actor and Source, holds invalidation until the local transaction commits, and must authenticate current identity, permissions, selected business, reviewer qualifications, exact case, current consent and accepted scope against authoritative providers. Its source revision covers every binding and it must serialize revocation against command admission. A cached projection cannot implement this port. No provider HTTP interface is invented here.

The database repository locks the case, writes state/history, actor-bound receipt, audit and shared outbox in one transaction. Evidence is returned only through its audited private read. Reassignment removes old access before receipt lookup. A read still checks current authority if its screen remains open. Correction is followed by a new claim against the corrected source; a new verdict preserves old decisions. Neither a verdict nor its event creates a grant or payment authority.

The retention function produces redaction instructions for the lifecycle owner. That owner must remove upstream synthetic facts, reasons and any exports at the same deadline, preserving obligation holds and minimal references only. It must enforce the one-year reference ceiling and seven-day export response. An evidence tombstone prevents this module from returning deleted proof. A later evidence submission requires a new case. Scheduled deletion, export delivery, durable denial audits, provider fences, actual database rollback/outbox restart and authenticated upstream integration remain connected proofs.
