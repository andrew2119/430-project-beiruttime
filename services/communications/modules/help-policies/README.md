# Help policy adapters

`create_router` composes public guidance and a private read without registering a shared runtime route. Supply the versioned public guidance document from the contracts subtree and an asynchronous current-context dependency. That dependency resolves the path record using the authenticated identity, selected business and current record scope; it must never derive actor authority from client-supplied identifiers. The provider rechecks current authority and access revision before and after reading E03. Supply an authoritative UTC clock at use time. No authorization cache or accepted-policy write is created here.

The private adapter applies no-store responses and bounds the action reference, record reference, revision, text and provider wait. Provider failures return unavailable without exception text. Retry performs another read with the same binding; there is no receipt, fee or message to duplicate. The original versioned acceptance remains durable in E03. Public help needs no identity dependency, and missing contact data does not become an invented contact route.

Shared runtime composition, the actual E03 adapter and M04 current-scope proof are deferred to their owners. Local fixtures establish the read boundary only. They do not establish connected permission, persistence or delivery success.
